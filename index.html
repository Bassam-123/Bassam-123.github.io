Selected Projects

Hierarchical RAG System for PDF Question Answering (March 2026)

  • Built a scalable multi-document QA system over 100+ PDF files using a two-stage hierarchical retrieval pipeline (document-level + chunk-level), reducing irrelevant context retrieval by ~40%.
  • Generated dense vector embeddings using BAAI/bge-large-en and indexed 10,000+ text chunks in FAISS, achieving sub-second query latency.
